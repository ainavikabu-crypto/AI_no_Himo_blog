# アイヒモのSEOブログ自動投稿ワークフロー（Tavily版）

## 概要

このn8nワークフローは、キーワードを入力するだけで、**Tavily AI**で最新情報を調査し、**アイヒモ**というキャラクターの視点でSEO最適化されたブログ記事を自動生成し、WordPressに投稿するエンドツーエンドの自動化システムです。

### アイヒモとは？

**アイヒモ**は、「AIのひもになりたい」ブログの執筆キャラクターです。

- **名前**: アイヒモ（女性）
- **属性**: AIのひもを目指す実験家
- **一人称**: 「私」
- **語尾**: 「です、ます調」
- **性格**: 明るく親しみやすい、知的で論理的だが硬すぎない
- **特徴**: 体験談ベースで語る、正直で率直、ポジティブ

アイヒモは、業務で生成AIを活用するうちに「自分が働く必要ないのでは？」と気づき、「AIのひも」になることを目指し始めた実験家です。

### 主な機能

✅ **Tavily AI検索**: 最新情報を高精度に自動調査
✅ **アイヒモのブログ執筆**: CLAUDE.meのキャラクター設定に基づいた体験談ベースの記事
✅ **SEO最適化**: タイトル、メタディスクリプション、スラッグを自動生成
✅ **WordPress自動投稿**: 下書きとして自動投稿
✅ **アイキャッチ画像**: 自動で画像をアップロードして設定
✅ **Telegram通知**: 完了通知を受信

## ワークフローの流れ

```
1. フォームでキーワード入力
   ↓
2. Tavily AIで最新情報を調査（HTTP Requestノード）
   ↓
3. Codeノードで調査結果を整形
   ↓
4. アイヒモブログライターがブログ記事を生成（2000-3000文字）
   - キャラクター設定（CLAUDE.me）に基づく
   - 体験談ベース
   - 「です、ます調」
   - 明るく親しみやすい
   ↓
5. 並行処理：
   - HTML形式に変換
   - タイトル・スラッグ・メタディスクリプション生成
   ↓
6. データを結合してWordPressに投稿
   ↓
7. アイキャッチ画像をアップロード・設定
   ↓
8. Telegramで完了通知
```

## 必要な認証情報

このワークフローを使用するには、以下のAPIキーと認証情報が必要です：

### 1. Tavily API
- **取得方法**: https://tavily.com/
- **料金**: 無料プラン: 1,000リクエスト/月、有料プラン: $29/月（10万リクエスト）
- **n8nでの設定**: Credentials → HTTP Header Auth
  - Header Name: `api-key`
  - Header Value: `tvly-YOUR_API_KEY`

### 2. OpenAI API
- **取得方法**: https://platform.openai.com/api-keys
- **必要なモデル**: gpt-4o-mini
- **n8nでの設定**: Credentials → OpenAI → API Key を入力

### 3. WordPress API
- **必要な情報**:
  - WordPressサイトURL
  - アプリケーションパスワード
- **取得方法**:
  1. WordPress管理画面 → ユーザー → プロフィール
  2. 「アプリケーションパスワード」セクションまでスクロール
  3. 新しいアプリケーション名（例：n8n）を入力して「新しいアプリケーションパスワードを追加」
  4. 生成されたパスワードをコピー
- **n8nでの設定**: Credentials → WordPress
  - Site URL: `https://your-site.com`
  - Username: WordPressユーザー名
  - Password: アプリケーションパスワード

### 4. Telegram Bot（オプション）
- **取得方法**:
  1. Telegramで @BotFather を検索
  2. `/newbot` コマンドで新しいボットを作成
  3. Bot Tokenを取得
  4. 自分のChat IDを取得（@userinfobot を使用）
- **n8nでの設定**: Credentials → Telegram
  - Access Token: Bot Token
- **環境変数**: `TELEGRAM_CHAT_ID` に自分のChat IDを設定

## インストール手順

### 1. n8nをセットアップ

```bash
# Dockerを使用する場合
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

# npmを使用する場合
npm install n8n -g
n8n start
```

### 2. ワークフローをインポート

1. n8nにアクセス（通常は http://localhost:5678）
2. 左側のメニューから「Workflows」を選択
3. 右上の「Import from File」をクリック
4. `seo-blog-aihimo-tavily.json` を選択してインポート

### 3. 認証情報を設定

1. ワークフロー内の各ノードを開く
2. 赤い警告が表示されているノードの認証情報を設定：
   - **Tavily検索実行**: Tavily API認証情報を選択
   - **GPT-4o-mini**: OpenAI API認証情報を選択
   - **HTML作成**: OpenAI API認証情報を選択
   - **OpenAI Chat Model**: OpenAI API認証情報を選択
   - **WordPress投稿**: WordPress認証情報を選択
   - **WordPressに画像アップロード**: WordPress認証情報を選択
   - **WordPress投稿に画像設定**: WordPress認証情報を選択
   - **完了通知**: Telegram認証情報を選択（オプション）

### 4. WordPressサイトURLを更新

以下のノードで `your-wordpress-site.com` を実際のWordPressサイトURLに置き換えてください：

- **WordPressに画像アップロード** ノード
- **WordPress投稿に画像設定** ノード

### 5. ワークフローを保存

右上の「Save」ボタンをクリックしてワークフローを保存します。

### 6. ワークフローをアクティブ化

右上のトグルスイッチをクリックしてワークフローをアクティブにします。

## 使用方法

### 基本的な使い方

1. n8nでワークフローを開く
2. 「フォーム送信時」ノードをクリック
3. 「Test URL」または「Production URL」をコピー
4. ブラウザで開く
5. フォームにキーワードを入力（例：「2025年のAI技術トレンドと日本企業への影響」）
6. 送信ボタンをクリック
7. ワークフローが自動実行され、数分後にWordPressに投稿されます

### サンプルキーワード

以下のようなキーワードを試してみてください：

- 2025年のAI技術トレンドと日本企業への影響
- リモートワーク時代の生産性向上ツール
- DX推進における中小企業の課題と解決策
- n8nで業務自動化を実現する方法
- AIチャットボットの導入事例
- ノーコードツールの最新動向

### アイヒモのキャラクター設定

アイヒモのブログ記事は、以下の特徴を持ちます：

- **体験談ベース**: 「実は最近〜」「〜してみたら」などのフレーズ
- **です、ます調**: 明るく親しみやすい丁寧な表現
- **正直で率直**: うまくいったことも、そうでなかったことも包み隠さず
- **ポジティブ**: 否定的な表現を避け、学びや次のステップに変換
- **絵文字は最小限**: 0〜2個程度

詳細は `Writer/CLAUDE.me` ファイルを参照してください。

## Perplexity版との違い

### Perplexity版（`seo-blog-auto-publisher-ja.json`）

- Perplexity API（sonar-pro）を使用
- 一般的なビジネス/テクノロジー記事
- キャラクター設定なし

### Tavily版（`seo-blog-aihimo-tavily.json`）- 推奨

- **Tavily API**を使用（より高精度な検索）
- **アイヒモのキャラクター**で執筆
- **Codeノード**で検索結果を整形
- **体験談ベース**の親しみやすい記事
- **Writer/CLAUDE.me**のガイドラインに準拠

## カスタマイズ方法

### 1. アイヒモのキャラクターを変更

**Writer/CLAUDE.me**ファイルを編集して、キャラクター設定を変更できます：

- 一人称（「私」→「僕」「自分」など）
- 語尾（「です、ます調」→「だ、である調」など）
- 話し方の特徴
- 背景ストーリー

変更後、**アイヒモブログライター**ノードのプロンプトも更新してください。

### 2. 記事の文字数を変更

**アイヒモブログライター**ノードのプロンプトで以下の部分を変更：

```
- 2000〜3000文字の長さにする
```

### 3. Tavily検索の精度を調整

**Tavily検索実行**ノードの`jsonBody`で以下のパラメータを調整：

```json
{
  "search_depth": "advanced",  // "basic" または "advanced"
  "max_results": 10,            // 検索結果の数（1-20）
  "include_answer": true,       // AI要約を含めるか
  "include_domains": [],        // 特定のドメインのみ検索
  "exclude_domains": []         // 除外するドメイン
}
```

### 4. HTML構造をカスタマイズ

**HTML作成**ノードのプロンプトで必須構造を変更：

例：FAQセクションを削除する場合

```
**必須構造（この順序で）：**
1. タイトル（H2）
2. 推定読了時間
3. 重要ポイント（3-5箇条書き）
4. 目次
5. メインコンテンツ
6. まとめセクション
```

## トラブルシューティング

### エラー: Tavily API認証エラー

**原因**: APIキーが正しく設定されていない

**解決方法**:
1. Tavily APIキーを再確認（`tvly-`で始まる）
2. n8nのHTTP Header Auth認証情報を確認:
   - Header Name: `api-key`
   - Header Value: `tvly-YOUR_API_KEY`

### エラー: Codeノードでエラー

**原因**: Tavilyの検索結果の構造が異なる

**解決方法**:
1. **Tavily検索実行**ノードを実行して結果を確認
2. **Tavily結果を整形**ノードのコードを調整
3. Tavilyのドキュメントを参照: https://docs.tavily.com/

### 生成された記事がアイヒモらしくない

**原因**: プロンプトが十分に詳細でない、またはCLAUDE.meの設定が反映されていない

**解決方法**:
1. **Writer/CLAUDE.me**ファイルを確認
2. **アイヒモブログライター**ノードのプロンプトがCLAUDE.meの設定を反映しているか確認
3. プロンプトに具体例を追加

### Tavily検索結果が少ない/不適切

**解決方法**:
1. `search_depth`を`advanced`に変更
2. `max_results`を増やす（最大20）
3. `include_domains`で信頼できるドメインを指定
4. キーワードをより具体的にする

## 技術詳細

### ノード構成

1. **フォーム送信時**: Webhookトリガー
2. **Tavily検索実行**: HTTP Requestノード（POST）
3. **Tavily結果を整形**: Codeノード（JavaScript）
4. **アイヒモブログライター**: AI Agentノード + GPT-4o-mini
5. **HTML作成**: OpenAI LLMノード
6. **タイトル・スラッグ・メタ作成**: AI Agentノード + 構造化出力パーサー
7. **結合**: Mergeノード（3入力）
8. **ブログ詳細を結合**: Aggregateノード
9. **HTMLクリーンアップ**: Setノード
10. **WordPress投稿**: WordPressノード
11. **画像処理**: HTTP Requestノード（画像取得・アップロード・設定）
12. **完了通知**: Telegramノード

### Codeノードの役割

**Tavily結果を整形**ノードは、Tavily APIの検索結果を以下のように処理します：

1. AI要約を抽出
2. 検索結果（タイトル、内容、URL）を整形
3. マークダウン形式でテキストを生成
4. AIエージェントに渡しやすい形式に変換

## よくある質問

### Q: Perplexity版とTavily版、どちらを使うべきですか？

A: **Tavily版**を推奨します。理由：
- より高精度な検索結果
- アイヒモのキャラクターで親しみやすい記事
- Codeノードで柔軟なカスタマイズが可能
- コストが低い（約$0.03/記事）

### Q: アイヒモのキャラクターを別のキャラクターに変更できますか？

A: はい、可能です。
1. **Writer/CLAUDE.me**ファイルを編集
2. **アイヒモブログライター**ノードのプロンプトを更新
3. キャラクター名、性格、口調などを変更

### Q: Tavily以外の検索APIは使えますか？

A: はい、以下の検索APIも使用可能です：
- Google Custom Search API
- Bing Search API
- SerpAPI

**Tavily検索実行**と**Tavily結果を整形**ノードを変更してください。

### Q: 複数のWordPressサイトに投稿できますか？

A: はい、ワークフローを複製して、それぞれ異なるWordPress認証情報を設定することで可能です。
