# n8n Cloud IPアドレスホワイトリスト設定ガイド（エックスサーバー）

## 🎯 この方法が最適な場合

- エックスサーバーでWordPressを運用している
- n8n Cloudを使用している
- `ETIMEDOUT` エラーが発生している
- REST API制限をOFFにしても解決しない
- WAFもOFFにしても解決しない

**この方法で、セキュリティを維持しながらn8n Cloudからのアクセスを許可できます。**

## ✅ エックスサーバーでのホワイトリスト設定手順

### ステップ1: サーバーパネルにログイン

1. エックスサーバーの**サーバーパネル**にログイン
   - https://www.xserver.ne.jp/login_server.php

### ステップ2: WordPress セキュリティ設定を開く

1. **「WordPress セキュリティ設定」**をクリック
2. 対象ドメインを選択

### ステップ3: 国外IPアクセス制限設定を開く

1. **「国外IPアクセス制限設定」**タブをクリック

### ステップ4: REST API ホワイトリストを設定

1. **「REST API アクセス制限」**の行を探す

### ステップ6: 設定を保存

1. すべてのIPアドレスを入力したら、**「確認画面へ進む」**をクリック
2. 内容を確認して**「設定する」**をクリック

### ステップ7: REST API制限を再度ONにする

1. **「REST API アクセス制限」**を**「ON」**に設定
   - これで、ホワイトリストに登録したIPアドレス（n8n Cloud）からのみアクセス可能になります
   - セキュリティを維持しながらn8nを使用できます

2. **「設定する」**をクリック

### ステップ8: 設定反映を待つ

- 設定が反映されるまで**5〜15分**待ちます

### ステップ9: n8nでテスト実行

1. n8nワークフローで再度実行
2. 成功すれば完了！

## 🧪 テスト方法

### テスト1: ブラウザでREST APIにアクセス

```
https://あなたのサイト.com/wp-json/wp/v2/posts
```

**期待される結果：**
- 日本国内からアクセス → JSON形式のデータが表示される
- 他の国からアクセス → アクセス拒否（ホワイトリスト以外）

### テスト2: n8nで実行

n8nワークフローを実行：

**✅ 成功した場合：**
- `ETIMEDOUT` エラーが消える
- WordPressに投稿が作成される

**❌ まだエラーが出る場合：**
- 設定が反映されていない可能性（15分待つ）
- IPアドレスリストが最新でない可能性（公式ドキュメント確認）
- n8nが新しいIPアドレスから接続している可能性

## 🔧 トラブルシューティング

### Q1: ホワイトリストに追加してもまだタイムアウトする

**A:** 以下を確認してください：

1. **設定が反映されているか確認**
   - 設定後15分待つ
   - サーバーパネルで設定を再確認

2. **REST API制限がONになっているか確認**
   - ホワイトリストは、REST API制限が「ON」の状態で機能します

3. **すべてのIPアドレスを追加したか確認**
   - 上記のIPアドレスリストをすべて追加

4. **n8nの最新IPアドレスを確認**
   - 公式ドキュメント（https://docs.n8n.io/manage-cloud/cloud-ip/）で最新リストを確認
   - IPアドレスが追加されている可能性

5. **n8nのワークフローを再実行**
   - キャッシュをクリア
   - ワークフローを保存し直す

### Q2: CIDR範囲をホワイトリストに追加する方法は？

**A:** エックスサーバーのホワイトリスト機能がCIDR表記をサポートしているか確認してください。

**サポートしている場合：**
```
20.52.126.0/28
20.218.238.112/28
```

**サポートしていない場合：**

**オプション1: ワイルドカードを使用**
```
20.52.126.*
20.218.238.*
```

**オプション2: 個別のIPアドレスに展開**

上記の「ステップ5」を参照して、すべてのIPアドレスを個別に入力してください。

### Q4: n8nが新しいIPアドレスを使い始めたらどうすればいい？

**A:** 以下の手順で対応してください：

1. **n8n公式ドキュメントで最新リストを確認**
   - https://docs.n8n.io/manage-cloud/cloud-ip/

2. **新しいIPアドレスをホワイトリストに追加**
   - サーバーパネル → WordPress セキュリティ設定 → ホワイトリスト編集

3. **定期的にIPアドレスリストを確認**
   - 月1回程度、公式ドキュメントで確認することを推奨

4. **n8nからのメール通知を確認**
   - n8nがIPアドレスを変更する際、事前に通知する場合があります

## 📊 この方法のメリット・デメリット

### メリット

✅ **セキュリティを維持**
- 国外IPアクセス制限を「ON」にしたまま運用可能
- n8n Cloud以外の不正アクセスはブロック

✅ **n8n Cloudをそのまま使用可能**
- セルフホスト不要
- n8n Cloudの便利な機能をそのまま利用

✅ **設定が簡単**
- サーバーパネルから数クリックで完了
- `.htaccess`の編集不要

### デメリット

⚠️ **IPアドレスの管理が必要**
- n8nがIPアドレスを変更した場合、再設定が必要

⚠️ **入力が手間**
- 多数のIPアドレスを個別に入力する必要がある（ワイルドカードが使えない場合）

⚠️ **完全な保証はない**
- n8nが新しいIPアドレスを追加した場合、即座に対応できない可能性

## 📝 まとめ

エックスサーバーのWordPressセキュリティ設定で、n8n CloudのIPアドレスをホワイトリストに追加することで、以下が実現できます：

1. ✅ セキュリティを維持しながらn8n Cloudを使用
2. ✅ `ETIMEDOUT` エラーを解決
3. ✅ 国外からの不正アクセスをブロック

**推奨される運用方法：**

1. **短期（今すぐ）：** この方法でホワイトリスト設定
2. **中期（1ヶ月後）：** 定期的にIPアドレスリストを確認
3. **長期（3ヶ月後）：** n8nセルフホスト（日本国内VPS）への移行を検討
