# アイヒモのSEOブログ自動生成 - Google Driveテスト版 セットアップガイド

このワークフローは、**WordPress投稿なし**でブログ記事を生成してGoogle Driveに保存するテスト版です。記事の品質確認やワークフローのテストに最適です。

## テスト版の特徴

### ✅ 含まれる機能

- Tavily検索による最新情報の調査
- アイヒモキャラクターによるブログ記事生成
- HTML変換とSEOメタデータ生成
- Google Driveへの自動保存
- Telegram通知（オプション）

### ❌ 削除された機能

- WordPress投稿
- WordPressへの画像アップロード
- アイキャッチ画像の設定

### 🎯 使用目的

- **記事の品質確認**: WordPress投稿前に記事内容をチェック
- **ワークフローのテスト**: 各ノードの動作確認
- **コスト削減**: WordPress APIを使わずにテスト
- **バックアップ**: 下書きの安全な保存

## 必要な準備

### 必須APIアカウント

1. **Tavily API** ([https://tavily.com](https://tavily.com))
   - 最新情報の検索に使用

2. **OpenAI API** ([https://platform.openai.com](https://platform.openai.com))
   - GPT-4o-miniでブログ記事生成

3. **Google Drive API** ([https://console.cloud.google.com](https://console.cloud.google.com))
   - 記事の保存に使用

### オプション

4. **Telegram Bot** (完了通知用)
   - @BotFatherで作成

### 不要なもの

- ❌ WordPress API（テスト版では不要）
- ❌ WordPressサイト

## セットアップ手順

### ステップ1: ワークフローのインポート

1. n8nにログイン
2. 左メニューから「Workflows」を選択
3. 右上の「Add Workflow」→「Import from File」
4. `アイヒモのSEOブログ自動生成_Tavily版_GoogleDriveテスト版.json` を選択
5. インポート完了

### ステップ2: API認証設定

#### Tavily API

1. 「Tavily検索」ノードを選択
2. 「Credential to connect with」をクリック
3. Tavily APIキーを入力して保存

#### OpenAI API

1. 「GPT-4o-mini」ノードを選択
2. OpenAI APIキーを入力して保存
3. 「HTML作成」ノードにも同じ認証情報を設定

#### Google Drive API

詳細な手順は以下の通りです：

**Google Cloud Consoleでの設定:**

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. プロジェクトを作成または選択
3. 「APIとサービス」→「ライブラリ」→「Google Drive API」を有効化
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
5. アプリケーションの種類：「ウェブアプリケーション」
6. 承認済みのリダイレクト URI:
   ```
   https://app.n8n.cloud/rest/oauth2-credential/callback
   ```
   または自分のn8nインスタンスのURL
7. クライアントIDとシークレットをコピー

**n8nでの設定:**

1. 「Google Driveにアップロード」ノードを選択
2. 「Create New Credential」
3. クライアントIDとシークレットを入力
4. 「Connect my account」でGoogleアカウント認証
5. 保存

### ステップ3: Google Drive保存先フォルダの設定

1. Google Driveで保存用フォルダを作成
   - 推奨名：「アイヒモブログ記事（テスト）」

2. フォルダIDを取得
   - フォルダを開いてURLを確認
   ```
   https://drive.google.com/drive/folders/[ここがフォルダID]
   ```

3. n8nの「Google Driveにアップロード」ノードで設定
   - **Drive**: My Drive
   - **Folder**: フォルダIDを入力

### ステップ4: Telegram通知設定（オプション）

1. Telegram Botを作成（@BotFatherで）
2. Bot Tokenを取得
3. チャットIDを取得
4. n8nの環境変数に設定
   ```
   TELEGRAM_CHAT_ID=あなたのチャットID
   ```
5. 「完了通知」ノードにBot Tokenを設定

### ステップ5: ワークフローの保存と有効化

1. 右上の「Save」ボタンをクリック
2. 「Active」スイッチをONにする
3. 「フォーム送信時」ノードの「Test URL」をコピー

## 使い方

### 基本的な実行方法

1. **フォームURLにアクセス**
   - 「フォーム送信時」ノードの「Test URL」をブラウザで開く

2. **キーワード入力**
   - 調査したいキーワードを入力
   - 例：「2025年のAI技術トレンドと日本企業への影響」

3. **送信**
   - フォームを送信すると自動的に処理開始

4. **処理待機**
   - 完了まで5-10分程度

5. **結果確認**
   - Google Driveの指定フォルダを確認
   - HTMLファイルがダウンロードされている

### 生成されたファイルの確認方法

#### ファイル名の見方

```
2025-01-17_14-30-45_ai-automation-trial.html
     ↓           ↓              ↓
   日時      タイムスタンプ    スラッグ
```

#### ファイルを開く

1. Google Driveからダウンロード
2. ブラウザで開く（ダブルクリック）
3. 以下が表示されます：
   - **テスト版バッジ**（オレンジ）
   - メタデータ（タイトル、スラッグ、メタディスクリプション、作成日時）
   - 記事コンテンツ（HTML形式）

#### 記事の確認ポイント

- [ ] タイトルが適切か
- [ ] 記事内容が自然な日本語か
- [ ] アイヒモの口調・キャラクターが反映されているか
- [ ] SEOメタディスクリプションが適切か
- [ ] 出典URLが含まれているか
- [ ] 文字数が2000-3000文字程度か

### Telegram通知の内容

通知設定済みの場合、以下のメッセージが届きます：

```
✅ アイヒモのブログ記事が完成しました（テスト版）

作成日時：2025-01-17 14:30:45
タイトル：AIで業務自動化を試してみた話

📁 Google Drive: [リンク]

※ このテスト版ではWordPress投稿は行いません。
記事内容を確認後、本番版ワークフローで投稿してください。
```

**テスト版:**
```
フォーム → Tavily検索 → ブログ生成 → HTML変換 → Google Drive → 完了

```

### 使い分け

**テスト版を使う場合:**
- 記事の品質を事前確認したい
- ワークフロー自体のテストを行う
- WordPress環境がまだ準備できていない
- バックアップだけが欲しい

**本番版を使う場合:**
- 記事を直接WordPressに投稿したい
- アイキャッチ画像も自動設定したい
- 下書きとして即座に保存したい

## トラブルシューティング

### エラー: Tavily検索が失敗する

**原因:**
- Tavily APIキーが無効
- APIクォータ超過

**解決策:**
1. Tavily APIキーを確認
2. [Tavily Dashboard](https://tavily.com) でクォータを確認

### エラー: ブログ生成が失敗する

**原因:**
- OpenAI APIキーが無効
- トークン制限超過

**解決策:**
1. OpenAI APIキーを確認
2. GPT-4o-miniのクォータを確認
3. 検索結果が多すぎる場合は、キーワードを具体化

### エラー: Google Driveアップロードが失敗する

**原因:**
- Google Drive認証エラー
- フォルダIDが間違っている

**解決策:**
1. Google Drive認証を再設定
2. フォルダIDを再確認
3. フォルダの権限を確認（認証アカウントがアクセスできるか）

### ファイルが見つからない

**確認事項:**
1. Google Driveの指定フォルダを確認
2. ワークフローの実行ログを確認（n8nで「Executions」タブ）
3. エラーメッセージがないか確認

### HTMLファイルが正しく表示されない

**原因:**
- ブラウザのセキュリティ設定
- ファイルの文字エンコーディング

**解決策:**
1. Google Driveからダウンロードしてからブラウザで開く
2. 別のブラウザで試す（Chrome、Firefox、Safariなど）
3. テキストエディタで開いて文字化けがないか確認

## 次のステップ

### テスト版で記事を確認した後

1. **記事内容が良好な場合**
   - 本番版ワークフロー（Google Drive対応版）を使用
   - WordPressに自動投稿

2. **記事内容を改善したい場合**
   - アイヒモブログライターのプロンプトを調整
   - 検索キーワードを見直し
   - 再度テスト版で生成

3. **ワークフローをカスタマイズしたい場合**
   - プロンプトの調整
   - HTML構造の変更
   - メタデータ生成ロジックの調整

### カスタマイズ例

#### 1. ファイル名を変更

「Google Drive用ドキュメント作成」ノードの`fileName`を変更：

```javascript
// タイトルベース
const fileName = `${metadata.title}.html`;

// 日付 + タイトル
const fileName = `${timestamp.split('_')[0]}_${metadata.title}.html`;
```

#### 2. HTMLテンプレートを変更

同じノードの`fullDocument`変数を編集して、デザインを変更できます。

#### 3. Telegram通知をカスタマイズ

「完了通知」ノードのテキストを変更：

```
✅ ブログ記事完成

📝 {{ $('ブログ詳細を結合').item.json.data[2].output.title }}
🔗 {{ $json.webViewLink }}

文字数：約{{ $('アイヒモブログライター').item.json.output.length }}文字
```
