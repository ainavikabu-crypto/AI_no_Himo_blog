# SEO最適化ブログ自動投稿ワークフロー

## 概要

このn8nワークフローは、キーワードを入力するだけで、Perplexity AIで最新情報を調査し、OpenAI GPT-4を使用してSEO最適化されたブログ記事を自動生成し、WordPressに投稿するエンドツーエンドの自動化システムです。

### 主な機能

✅ **自動リサーチ**: Perplexity APIで最新情報を自動調査
✅ **AI記事生成**: GPT-4o-miniで高品質な日本語ブログを自動作成
✅ **SEO最適化**: タイトル、メタディスクリプション、スラッグを自動生成
✅ **WordPress自動投稿**: 下書きとして自動投稿
✅ **アイキャッチ画像**: 自動で画像をアップロードして設定
✅ **通知機能**: Telegramで完了通知を受信

## ワークフローの流れ

```
1. フォームでキーワード入力
   ↓
2. Perplexity AIで最新情報を調査
   ↓
3. 調査結果のクリーンアップ
   ↓
4. AI Agentがブログ記事を生成（2000-3000文字）
   ↓
5. 並行処理：
   - HTML形式に変換
   - タイトル・スラッグ・メタディスクリプション生成
   ↓
6. データを結合してWordPressに投稿
   ↓
7. アイキャッチ画像をアップロード・設定
   ↓
8. Telegramで完了通知
```

## 必要な認証情報

このワークフローを使用するには、以下のAPIキーと認証情報が必要です：

### 1. OpenAI API
- **取得方法**: https://platform.openai.com/api-keys
- **必要なモデル**: gpt-4o-mini
- **n8nでの設定**: Credentials → OpenAI → API Key を入力

### 2. Perplexity API
- **取得方法**: https://www.perplexity.ai/settings/api
- **必要なモデル**: sonar-pro
- **n8nでの設定**: Credentials → HTTP Header Auth
  - Header Name: `Authorization`
  - Header Value: `Bearer YOUR_API_KEY`

### 3. WordPress API
- **必要な情報**:
  - WordPressサイトURL
  - アプリケーションパスワード
- **取得方法**:
  1. WordPress管理画面 → ユーザー → プロフィール
  2. 「アプリケーションパスワード」セクションまでスクロール
  3. 新しいアプリケーション名（例：n8n）を入力して「新しいアプリケーションパスワードを追加」
  4. 生成されたパスワードをコピー
- **n8nでの設定**: Credentials → WordPress
  - Site URL: `https://your-site.com`
  - Username: WordPressユーザー名
  - Password: アプリケーションパスワード

### 4. Telegram Bot（オプション）
- **取得方法**:
  1. Telegramで @BotFather を検索
  2. `/newbot` コマンドで新しいボットを作成
  3. Bot Tokenを取得
  4. 自分のChat IDを取得（@userinfobot を使用）
- **n8nでの設定**: Credentials → Telegram
  - Access Token: Bot Token
- **環境変数**: `TELEGRAM_CHAT_ID` に自分のChat IDを設定

## インストール手順

### 1. n8nをセットアップ

```bash
# Dockerを使用する場合
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

# npmを使用する場合
npm install n8n -g
n8n start
```

### 2. ワークフローをインポート

1. n8nにアクセス（通常は http://localhost:5678）
2. 左側のメニューから「Workflows」を選択
3. 右上の「Import from File」をクリック
4. `seo-blog-auto-publisher-ja.json` を選択してインポート

### 3. 認証情報を設定

1. ワークフロー内の各ノードを開く
2. 赤い警告が表示されているノードの認証情報を設定：
   - **OpenAI Chat Model**: OpenAI API認証情報を選択
   - **GPT-4o-mini**: OpenAI API認証情報を選択
   - **Perplexity調査実行**: Perplexity認証情報を選択
   - **WordPress投稿**: WordPress認証情報を選択
   - **WordPressに画像アップロード**: WordPress認証情報を選択
   - **WordPress投稿に画像設定**: WordPress認証情報を選択
   - **Telegram成功通知**: Telegram認証情報を選択（オプション）

### 4. WordPressサイトURLを更新

以下のノードで `your-wordpress-site.com` を実際のWordPressサイトURLに置き換えてください：

- **WordPressに画像アップロード** ノード
- **WordPress投稿に画像設定** ノード

### 5. ワークフローを保存

右上の「Save」ボタンをクリックしてワークフローを保存します。

### 6. ワークフローをアクティブ化

右上のトグルスイッチをクリックしてワークフローをアクティブにします。

## 使用方法

### 基本的な使い方

1. n8nでワークフローを開く
2. 「フォーム送信時」ノードをクリック
3. 「Test URL」または「Production URL」をコピー
4. ブラウザで開く
5. フォームにキーワードを入力（例：「2025年のAI技術トレンドと日本企業への影響」）
6. 送信ボタンをクリック
7. ワークフローが自動実行され、数分後にWordPressに投稿されます

以下のようなキーワードを試してみてください：

- ノーコードツールで業務効率化を実現する方法
- データ分析を活用したビジネス戦略

### ワークフロー実行結果の確認

1. **WordPress管理画面**: 投稿 → 下書き に新しい記事が追加されます

## カスタマイズ方法

### 1. ブログの文字数を変更

**ブログライターAIエージェント**ノードのプロンプトで以下の部分を変更：

```
- 2000〜3000文字の長さにする
```

### 2. ブログのトーン・スタイルを変更

**ブログライターAIエージェント**ノードのプロンプトで以下の部分を調整：

```
- プロフェッショナルでありながら魅力的なトーンを使用する
```

例：
- カジュアルなトーン: 「親しみやすく、会話的なトーンを使用する」
- フォーマルなトーン: 「ビジネス文書のような格式高いトーンを使用する」

### 3. 対象読者を変更

**ブログライターAIエージェント**ノードのプロンプトで以下の部分を変更：

```
- ビジネスパーソンや意思決定者が理解できるレベルで書く
```

例：
- 初心者向け: 「専門用語を避け、初心者でも理解できるように書く」
- 専門家向け: 「業界の専門家向けに、技術的な詳細を含めて書く」

### 4. アイキャッチ画像を変更

**画像URL設定**ノードで以下の部分を変更：

```javascript
https://images.unsplash.com/photo-1677442136019-21780ecad995?w=1200&h=630&fit=crop
```

推奨画像ソース：
- Unsplash: https://unsplash.com/
- Pexels: https://www.pexels.com/
- Pixabay: https://pixabay.com/

### 5. WordPress投稿ステータスを変更

**WordPress投稿**ノードの`status`フィールドを変更：

- `draft`: 下書き（デフォルト）
- `publish`: 即座に公開
- `pending`: レビュー待ち
- `private`: 非公開

### 6. Perplexityモデルを変更

**Perplexity調査実行**ノードのJSONボディで`model`を変更：

- `sonar-pro`: 最も高性能（デフォルト）
- `sonar`: 標準モデル
- `sonar-reasoning`: 推論に特化

## トラブルシューティング

### エラー: 認証に失敗しました

**原因**: API認証情報が正しく設定されていない

**解決方法**:
1. 各ノードの認証情報を再確認
2. APIキーが有効期限内であることを確認
3. APIキーに適切な権限があることを確認

### エラー: WordPress投稿に失敗しました

**原因**: WordPressのアプリケーションパスワードが無効、またはサイトURLが間違っている

**解決方法**:
1. WordPressのアプリケーションパスワードを再生成
2. サイトURLが正しいことを確認（例：`https://example.com`、末尾のスラッシュなし）
3. WordPressのREST APIが有効になっていることを確認

### エラー: Perplexity APIエラー

**原因**: APIクォータを超えた、またはAPIキーが無効

**解決方法**:
1. Perplexityのダッシュボードでクォータを確認
2. APIキーを再生成
3. リクエストレートが制限内であることを確認

### 記事の品質が低い

**原因**: 調査キーワードが曖昧、またはプロンプトが最適化されていない

**解決方法**:
1. より具体的なキーワードを入力
2. **ブログライターAIエージェント**ノードのプロンプトを調整
3. OpenAIのモデルを`gpt-4o`にアップグレード（コストは上がります）

### 画像のアップロードに失敗

**原因**: 画像URLが無効、またはWordPressのメディアアップロード制限

**解決方法**:
1. 画像URLが有効でアクセス可能であることを確認
2. WordPressのメディアアップロード設定を確認
3. 別の画像URLを試す

## よくある質問

### Q: 複数のWordPressサイトに投稿できますか？

A: はい、ワークフローを複製して、それぞれ異なるWordPress認証情報を設定することで可能です。

### Q: 予約投稿はできますか？

A: はい、n8nのSchedule Triggerノードを追加することで、定期的な自動投稿が可能です。

### Q: 記事を公開前に確認できますか？

A: デフォルトでは下書きとして投稿されるため、WordPress管理画面で確認・編集してから公開できます。

### Q: 他の言語でも使えますか？

A: はい、プロンプトを他の言語に翻訳することで、他の言語のブログも生成可能です。

### Q: 画像を自動生成できますか？

A: このワークフローには含まれていませんが、DALL-E 3やMidjourneyのAPIを統合することで可能です。
